# Как запускать ADP

1. `/andreev-sy-cursor-tools-adp`
2. Агент пришлёт короткий блок «Заполни и пришли…» — заполни поля, ответь одним сообщением.
3. Дальше Acceptance → работа (или уточняющие вопросы, если Need размыт).

Карточки AskQuestion в Cursor часто недоступны в Agent — поэтому основной UX = заполняемый блок в чате, не копипаста длинного примера.

## Пример ответа

```text
Need: экспорт пользователей в CSV как у инвойсов
Anchor: InvoiceExport / export-модуль (или: найди в репо)
Prove: project.md
Нельзя: новый framework, one-off скрипт, обход слоя якоря
```
