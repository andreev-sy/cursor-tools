# Как запускать ADP без копирования промпта

1. В Agent: `/andreev-sy-cursor-tools-adp`
2. Заполни карточки **AskQuestion** (чекбоксы / выбор) — оракул, запреты, якорь.
3. В чате допиши свободный текст: **Need** и при необходимости **Anchor** (путь/сосед).

Отдельный markdown-промпт копировать не нужно.

## Если карточек нет

Иногда `AskQuestion` недоступен (модель/режим). Тогда агент задаст те же пункты текстом — ответь коротко.

Либо сразу одной сообщением со skill:

```text
/andreev-sy-cursor-tools-adp

Need: …
Anchor: …
Нельзя: …
Prove: project.md / <команда>
```

## Зачем не «своя форма»

У Cursor skills нет UI «форма с полями» при `/skill`. Есть только карточки выбора (`AskQuestion`) + обычный чат для свободного текста.
